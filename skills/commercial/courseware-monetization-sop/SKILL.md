# 学科课件 0 到 1 变现全流程 SOP Skill (`courseware-monetization-sop`)

学科课件资料是教育赛道刚需、高复购、长期复利的黄金虚拟资产（公开课课件、新课标同步课件、主题班会、幼小衔接）。本 Skill 完整复现《学科课件 0 到 1 变现全流程 SOP》的 **12 步标准化流水线**，并与本仓库已安装的 `image-to-editable-pptx`（图片转可编辑 PPTX）和 `harness-anything-wps`（WPS/PPT 原生自动化构建）深度打通，实现从**对标解析、AI 配图、可编辑 PPTX 生成、配套教案+逐字稿生成、到小红书/闲鱼上架引流**的一站式交付。

## 1. 适用场景与触发时机

- 用户需要针对某一具体学科课文/课题（如小学语文《秋天的雨》、小学数学《认识分数》、主题班会《防溺水安全教育》）生成**全套可售卖的高溢价教学资料包**。
- 用户已有参考课件截图或旧课件，需要调用 Skill 拆解其教学逻辑与版式，重绘原创插图并合成 **100% 原生可编辑的 `.pptx` 课件**。
- 用户需要为做好或改好的 PPT 课件一键补齐**新课标标准教学设计（教案 `.docx`）**与**逐页课堂讲授逐字稿（含互动问答与翻页提示）**。
- 用户需要生成配套的**商品详情页文案、新人优惠券定价策略**及**小红书爆款种草图文笔记（含标题、正文、话题标签、挂链引流话术）**。

## 2. 学科课件 0 到 1 变现 12 步完整 SOP 复现

### Step 01: 精准找对标（锁定高需求爆款课题）
- **选品金标准**：优先选择**新课标必讲公开课名篇**（如语文三至六年级精读课文、古诗词三首、数学广角、开学第一课/期中家长会）。
- **对标筛选渠道**：在小红书、抖音、希沃白板、七彩学科网搜索近期点赞 > 500、评论区高频出现“求课件/怎么买/有逐字稿吗”的爆款笔记。

### Step 02: 上传课件至 Codex / Agent 调用 Skill 逆向解析
将对标课件（或长图/PDF/压缩包）输入本 Skill，自动解析出结构化 Markdown 教学蓝图（`COURSEWARE_BLUEPRINT.md`）：
- **教学闭环拆解**：情境导入（创设大任务情境） -> 初读感知（字词闯关） -> 精读品析（核心段落思维导图） -> 拓展迁移（小练笔/课堂活动） -> 板书总结与分层作业。
- **版式与视觉风格拆解**：提取主色/辅助色/背景色 HEX 色值、字体层级、每页卡片布局（左右分栏、三卡并列、时间轴、中心辐射图）。

### Step 03: GPT / 即梦 AI 理解 MD 文档批量生图
根据拆解出的 Markdown 蓝图，由本 Skill 自动生成**风格高度统一的画面提示词（Prompt Pack）**：
- **无字底图提示词**：预留中央或右侧 60% 干净浅色留白区域供 PPT 放置文字卡片。
- **知识点插图提示词**：统一采用“国风儿童绘本水彩插画”或“扁平矢量教育插画”风格，批量生成 8-12 张 16:9 高清配图。

### Step 04-07: PPT 组装、可画文字擦除与可编辑文字还原
针对传统 AI 生图自带乱码文字或旧课件同质化问题，提供双通道解决方案：
- **通道 A（云端精细改版）**：将配图拖入 PPT -> 上传至可画（Canva）使用“魔术橡皮擦/文字擦除”清空图片内杂字 -> 还原规范教学文字；或对压缩包素材使用批量 OCR 工具（`skills/image-to-editable-pptx/scripts/ocr_lines.py`）一键提取全部图片文字转可编辑文本。
- **通道 B（本地/沙箱原生构建，推荐）**：直接通过本仓库 Python PPTX 引擎或 `skills/harness-anything` / `skills/image-to-editable-pptx`，将 AI 生成的纯净无字插图作为视觉素材，搭配**原生可编辑形状卡片、色带、表格、徽章与文本框**直接构建 `.pptx`，从根源上保证 100% 文本双击可改、零版权风险、排版对齐工整！

### Step 08: 学科课件逐字稿 + 教案生成 Skill（提升产品溢价 300%）
单卖 PPT 只能卖 3-5 元，**“精品可编辑 PPT + 配套新课标教案 + 逐页逐字稿”三件套可卖 19.9-39.9 元**！
本 Skill 自动根据 PPT 每页内容生成配套 Word 文档（`.docx`）：
1. **新课标标准教案**：
   - 课题基本信息（年级、课时、课型）
   - 核心素养四大目标（文化自信、语言运用、思维能力、审美创造）
   - 教学重难点分析
   - 教学准备与多媒体资源
   - 教学过程详案（导入 -> 新授三任务群 -> 巩固 -> 小结）
   - 结构化板书设计图与分层作业设计
   - 教学反思模板
2. **逐页课堂逐字稿（Verbatim Teaching Script）**：
   - 严格对应 PPT 第 1 页至最后 1 页。
   - 每页包含：`【PPT 页码与画面提示】`、`【教师口播原话】`、`【预设学生回答】`、`【课堂评价语与过渡语】`、`【翻页/板书动作提示】`，新教师拿着就能直接上台讲公开课！

### Step 09: 商品详情页设计、店铺上架与新人优惠券设置
- **SKU 阶梯定价设计**：
  - 引流单课体验装：9.9 元（含可编辑 PPT + 教案 + 逐字稿）
  - 单元全套精品包：29.9 元（立省 50%，主推利润款）
  - 全册同步大合集：69.9 元（设置**新人关注立减 10 元优惠券**，到手 59.9 元，促成高客单成交）
- **详情页 5 张主图自动规划**：首图痛点封面 + 全套文件目录截图 + PPT 高清内页九宫格 + 逐字稿/教案实拍预览 + 自动秒发说明。

### Step 10-12: 小红书种草笔记制作、标题话题创作与挂链发布
- **笔记高赞形式**：实拍平板/电脑播放课件翻页效果（或 6 张高清内页 + 逐字稿左右对比拼图）。
- **爆款标题公式库**：
  - `公开课拿了一等奖！全靠这套《XX》大单元情境课件（附逐字稿）`
  - `熬夜三天肝出来的《XX》新课标课件！老师们直接抄作业`
  - `被教研员夸爆的《XX》公开课PPT+逐字稿，课堂氛围直接拉满！`
- **精准话题标签**：`#小学语文公开课 #新课标教学设计 #课件分享 #公开课课件 #青年教师公开课 #教案逐字稿`
- **发布与挂链实操**：笔记发布时直接挂载小红书店铺商品链接（或在评论区置顶引导店铺同名下单）；配合本仓库 `code/media-bridge/xhs_publish.py`（`sau xiaohongshu`）可实现本机自动化排期发布。
