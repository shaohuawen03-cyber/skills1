# Accio Work 实操复现：一条完整流程走到底

> 目标：不看理论，跟着做一遍。跑通「1688 找货源源头工厂 → 比价 → 自动询盘砍价」一条完整流程。
> 总耗时约 20-30 分钟。每步都给出【在哪做】【贴什么】【会看到什么】。

---

## 第 0 步：开工前的一次性准备（5 分钟）

1. 打开 Accio Work（装在 `E:\AccioWork`，双击桌面图标）。
2. 登录：手机号或邮箱注册，也可用阿里巴巴国际站账号直接登录。
3. 设置 → 通用：
   - 界面语言：中文
   - 默认工作目录：`E:\AccioWorkData`（Agent 生成的文件都存这里）
4. 左侧「连接器/应用」里授权 **1688**（必选）和 **邮箱**（Gmail/163/QQ 均可，第 3 步发询盘用）。

验收点：连接器里 1688 显示「已连接」。

---

## 场景设定（照抄即可）

假设您是做户外水具的商家，要找一款 **硅胶折叠水杯** 的货源，
量 2000 个，目标拿货价 8 元以内，要求支持 OEM 贴牌。

---

## 第 1 步：选品验证（5 分钟）

【在哪做】左上角「新建任务」，把下面整段贴进输入框：

```
分析硅胶折叠水杯这个品类：海外近 90 天的需求趋势和热度（Google/TikTok 维度），
1688 上的主流价格带和销量区间，判断现在入场是不是好时机。
给我结论：进 / 不进，以及理由（3 条以内）。确认数据范围后再执行。
```

【会看到什么】Accio 先列出它打算查的范围（平台、时间窗）让您确认，
然后开始跑数据，产出一份「品类判断」：趋势结论 + 价格带表 + 3 条理由。
全程约 3-5 分钟，右下角能看到它在调用哪些工具。

验收点：结论页出现，且写明「进」或「不进」。

---

## 第 2 步：1688 找源头工厂（5 分钟）

【在哪做】同一个会话继续贴：

```
在 1688 找 5 家做硅胶折叠水杯的源头工厂，要求：
- 剔除贸易商和二手贩子，只要源头工厂/实力商家
- 支持 OEM 贴牌，MOQ 500 个以内
- 以 2000 个的量级报出厂价
输出对比表：厂家名、出厂价、MOQ、交期、评分、定制能力，按性价比排序。
```

【会看到什么】Accio 调用 1688 选品/以图搜货能力，产出一张 5 行的对比表，
第一行就是它推荐的最优厂家。表里能看到「源头工厂」标记（贸易商已被剔除）。

验收点：表格 5 行齐全，有出厂价和交期两列。

---

## 第 3 步：自动询盘砍价（5 分钟）

【在哪做】继续贴：

```
给对比表里前 3 家发询盘邮件：
- 订单量 2000 个，目标价 8 元以内（报 7.5 元留砍价空间）
- 要求免费样品 2 个、交期 15 天内、OEM 激光 logo
- 发出后自动跟进，对方回复后多轮谈判，最终报价和条款汇总给我
```

【会看到什么】Accio 会弹出 **权限确认**（发邮件是敏感能力，需要您点「允许」）。
确认后它自动写英文/中文邮件、逐家发出，并在收件箱跟进回复。
谈判结果汇总成一张「最终条款表」（价格、样品、交期、付款方式）。

验收点：发件箱里有 3 封询盘邮件；任务产出里有最终条款表。
注意：对方人工回复可能要几小时，这一步可以先放着，Accio 会持续跟进。

---

## 第 4 步：落盘成文件（2 分钟）

【在哪做】最后贴：

```
把今天的选品结论、厂家对比表、询盘谈判结果整理成一份 Word 报告，
存到 E:\AccioWorkData\硅胶折叠水杯选厂报告.docx，附上下一步行动清单。
```

【会看到什么】Accio 生成 docx 并告诉您完整路径。打开确认三个表格都在。

验收点：`E:\AccioWorkData\硅胶折叠水杯选厂报告.docx` 存在且可打开。

---

## 常见卡点

| 现象 | 处理 |
| --- | --- |
| 输入指令后它先反问范围 | 正常，它在确认数据口径。点「确认」或补充一句范围即可 |
| 1688 连接器授权失败 | 重新登录 1688 账号再授权；或先用「网页版 1688 搜索」能力替代 |
| 发邮件没反应 | 看是不是权限弹窗被挡了；设置 → 权限 里把邮件设为「询问」 |
| 跑一半停了 | 左侧任务列表找到该任务点「继续」；或直接在会话里说「继续」 |
| 想换个品类复现 | 把「硅胶折叠水杯」全换成您的品类（如「宠物慢食碗」），其余不用改 |
