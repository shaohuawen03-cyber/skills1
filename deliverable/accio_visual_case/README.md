## 一、案例概述

| 项目 | 内容 |
|---|---|
| 客户画像 | 有自有工厂的 1688 卖家，产品做得好，但主图点击率低 [原文] |
| 痛点 | 请摄影师、美工成本高、周期长；图片"太工厂风"（白底不够白、场景不够美、详情页像说明书）[原文] |
| 核心卖点 | AI 出图对标 1688 头部卖家视觉标准；覆盖主图、详情页、首页装修、视频脚本；可即时修改；工厂风转电商风；批量出图（50 个品一天）[原文] |
| 促单方式 | 现场 Demo：客户给一张产品图，30 秒现场出一张主图对比 [原文] |
| 常见反对意见 | 有美工不需要 AI；AI 图没真实感；外面几毛钱的 AI 更便宜 [原文] |

## 二、Accio 操作全流程（教程）

目标：把一张工厂实拍图变成一组电商图（主图 + 场景图 + 详情页素材 + 视频脚本）。

### 步骤 1：准备输入
1. 准备产品实拍图（一张即可，越清楚越好）。[原文：现场用客户手机里的一张图即可]
2. 确认产品关键参数（材质、尺寸、颜色、功能）。出图是"基于真实产品参数生成"的，参数越完整越真实。[原文]

### 步骤 2：选择出图类型
按用途选择（原文四类）：**主图 / 详情页 / 首页装修 / 视频脚本**。[原文]
- 常规出图由 AI 做，创意大图由美工做。[原文]
- [待验证] Accio 里这四类入口的具体位置和名称。

### 步骤 3：选择风格
- 要真实感 → 白底图。
- 要吸引力 → 场景图（加使用场景、加模特）。[原文]
- 工厂风转电商风：把"工厂实拍图"转成"电商卖货图"，加场景、加模特、加文案。[原文]

### 步骤 4：生成与即时修改
- 第一版出来后，不满意直接用一句话修改：“换个背景”“加个使用场景”，几分钟重新出图。[原文]
- 不需要等美工排期。[原文]

### 步骤 5：批量处理多 SKU
- 工厂 SKU 多时，一个品几分钟出一组，批量完成。[原文]
- [推断] 批量入口与导出格式 [待验证]。

### 步骤 6：导出与上架
- 直接用出的主图上架，不用再改尺寸、加文字、调排版。[原文："产品图丢进去，主图直接出来，直接上架"]
- [待验证] 导出尺寸是否符合 1688 上传规范（需按平台最新规范核对）。

### 演示话术（现场用）
开场问产能与点击率 → 对比“美工 3 天的活，AI 几分钟” → 现场拿客户图出一张主图 → 客户说“这比我美工做的好多了”就进入促单。[原文]

## 三、不用 Accio 的复刻方案

我用自己的能力复刻这个案例：

1. **主图概念图**：已用图像生成做一张白底/浅灰底、居中留白的主图概念图，文件 `replica_main_image.png`（AI 生成，产品为示例，不是真实客户产品）。
2. **换背景/加场景**：可以用同一产品做两个版本（白底真实版、场景版），对应原文"真实感 vs 吸引力"的选择。
3. **详情页与首页**：网页版可以用 taste-skill 的电商/落地页方向（见第四节）；主图和批量出图不用它。
4. **视频脚本**：可以直接写脚本（原文只提到"视频脚本"，没有给格式）。
5. **批量**：用脚本按 SKU 循环调用生成，但每张图需要单独的产品图输入，这一步不能只靠文字完成。

**复刻的局限**：没有真实产品图之前，只能做概念图；真正用于 1688 的图，需要真实产品图作为输入，并按平台规范检查尺寸和白底。

## 四、taste-skill 是否适合这种设计

依据：仓库 `Leonxlnx/taste-skill`（已克隆并读取 `skills/taste-skill/SKILL.md` 与 `skills/imagegen-frontend-web/SKILL.md`）。

| 需求 | taste-skill 是否覆盖 | 说明 |
|---|---|---|
| 首页 / 落地页 视觉 | **适合** | 它专门做落地页与网页设计，有"反模板化"规则（避免千篇一律的卡片、紫色渐变等） |
| 详情页（网页版） | **基本适合** | `imagegen-frontend-web` 有"电商/商品页"方向（全屏产品图、柔和晕影、裁切），可以生成网页版详情页的设计参考图和 HTML/CSS |
| 1688 主图（正方形、白底、点击率导向） | **不适合（不直接覆盖）** | 仓库里没有 1688 主图尺寸、白底规范，也没有点击率（CTR）相关规则（已在 SKILL.md 中检索 `1688` / `CTR` / `click` / `main image` / `white background` 均无相关条目） |
| 视频脚本 | **不适合** | 它不处理视频 |
| 真实感（基于真实产品参数） | **不适合** | 它是风格规则，不管真实性 |

**结论**：taste-skill 适合"网页版的首页和详情页"（风格与版式），不适合"1688 主图、批量出图、视频脚本"。如果目标是复现这个案例的主图和批量出图，taste-skill 不是合适的工具，应该继续用 Accio 或专门的电商出图方法。
